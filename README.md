# 个人译站 · 公开下载安装

公开下载页：https://weifashi.github.io/personal-translate-downloads/

直接安装包：https://weifashi.github.io/personal-translate-downloads/PersonalTranslate-arm64.dmg

本仓库只包含安装二进制、静态下载页和校验信息，应用源码保持私有。
支持 Apple Silicon（arm64）、macOS13及以上；安装包由 GitHub Actions 构建并验证只读挂载、应用签名与内容。

双击打开 DMG，把“个人译站”拖进 Applications。软件是 ad-hoc 签名，未经过 Apple 公证；不会绕过系统安全设置或自动授予权限。
